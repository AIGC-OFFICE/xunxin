## 技术规范

| 项 | 要求 |
|---|---|
| 分辨率 | 至少 1200×800 像素，建议 1600×1067 |
| 格式 | 来源 JPG / PNG，**最终统一转 WebP**（保持现有 `.webp` 命名） |
| 比例 | 横向 3:2 或 4:3 |
| 文件大小 | 单图 ≤ 200KB（WebP 压缩后） |
| 色调 | 工业偏冷（蓝灰 / 钢灰）或暖工业（橙黄高光），**不要**饱和糖果色 |
| 主体 | 居中或黄金分割点；卡片裁剪后人物 / 物体不被截断 |

## 转换 / 压缩工具

- 在线：https://squoosh.app/ （Google 出品，浏览器内 WebP 转换）
- 命令行：`cwebp -q 80 input.jpg -o output.webp`
- 批量：`for f in *.jpg; do cwebp -q 80 "$f" -o "${f%.jpg}.webp"; done`
