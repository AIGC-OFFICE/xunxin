如何识别金属纯度：B 端采购的快速鉴别指南

2026-04-15 6 分钟阅读 循鑫研究

同样一吨"废铜"，紫铜（电解铜）和黄铜（铜锌合金）的对公结算价可以差出 35% 以上。在 生产性废旧金属回收 的 B 端业务里，纯度识别不是技术演练，而是直接的成本与定价问题。本文系统拆解工业现场识别金属纯度的三层方法、六大主流金属的快速鉴别要点，以及 XRF 光谱仪的正确使用边界。

一、识别金属纯度的三层方法

在专业的工业回收作业里，金属鉴别不是单点判断，而是三层递进：

  1. 外观与触觉 — 颜色、光泽、密度感、磁性，可在装车现场 5 秒内完成第一轮分类。
  2. 物理化学测试 — 磁力吸附、密度浮沉、酸液滴定，适合现场二次复核。
  3. 仪器检测 — XRF（X 射线荧光光谱）现场扫描、ICP-OES 实验室定量、火试金贵金属验证，作为对公结算前的最终背书。

三层方法的成本与精度成正比。一般生产性废金属批次在第一层即可锁价；价值含贵金属、含铜量高、或客户对计价存疑的批次，必须走完三层。

二、六大主流工业金属的现场识别要点

1. 紫铜（电解铜，含铜≥99.9%）

颜色玫瑰红，新切口呈现明亮金属光泽，氧化后转为暗红或绿（铜绿）。密度 8.96 g/cm³，明显沉手。无磁性。导电铜排、变压器线圈、空调铜管均属此类。结算价格紧贴 SHFE 沪铜主力合约。

2. 黄铜（铜锌合金，含铜 60-70%）

金黄色，比紫铜浅且暖。重量比紫铜略轻（密度 8.4-8.7 g/cm³），但仍属沉手金属。无磁性。多见于水暖管件、阀门、装饰件。常见误判：紫铜与黄铜在氧化后颜色趋同，必须新切口或打磨后判断。结算价约为紫铜的 65-75%。

3. 铝（纯铝 vs 铝合金）

银白色，密度 2.7 g/cm³，明显轻手。无磁性。纯铝软、易刻划；6061/6063 等结构铝合金硬度更高、表面常见挤压纹。关键鉴别：铝灰、铝渣、铝屑混料按"含铝量"折算，必须取样化验。回收价格按"光铝、铝合金、铝屑、铝灰"四档分别报价。

4. 304 / 316 不锈钢

表面呈冷调银灰，磨砂或镜面处理。磁力测试：304 / 316 等奥氏体不锈钢对磁铁弱磁或无磁；冷加工后可能出现微弱磁性，但远低于碳钢。酸滴鉴别：用专业不锈钢测试液（含氯化亚铁），304 与 316 显色不同（316 含钼）。区分意义：316 含镍 12%、钼 2-3%，价格比 304 高 25-40%。

5. 普通碳钢 vs 合金钢

颜色深灰至黑，强磁性。碳钢表面易生橙黄色铁锈；合金钢（如 40Cr、42CrMo）抗氧化性更好。火花测试：碳钢火花呈白色短爆星，工具钢火花更复杂、带分叉。结算时碳钢按"重废、中废、轻薄料"三档报价。

6. 锌合金 vs 锌锭

锌合金（压铸件）银灰带蓝调，密度 6.6-7.2 g/cm³，常见于汽车装饰件、五金件；纯锌锭密度 7.14 g/cm³，断面晶粒粗大。两者价格差约 15-25%。

三、XRF 光谱仪：现场鉴别的"主力武器"

手持式 XRF（X-Ray Fluorescence）光谱仪是 B 端回收现场的标准工具。原理是 X 射线激发样品发出特征荧光，通过光谱反推元素组成。

适用场景

  • 现场快速判定合金牌号（304 / 316 / 201、6061 / 7075、H62 / H68 等）
  • 含铜电缆的铜含量初判
  • 不锈钢混入碳钢比例排查
  • 含贵金属电子元件初筛（金、银、铂、钯）—— 这是 工业贵金属材料提取回收 的标准前置环节

常见误区与边界

  • 表面氧化层影响：油漆、铁锈、镀层会偏离真实读数，必须打磨干净。
  • 轻元素失准：XRF 对碳、硼、锂等轻元素灵敏度低，碳钢碳含量需要光谱仪 + 火花直读仪联用。
  • 合金成分不均：铸件、焊接件不同部位读数可能不同，需多点取样。
  • 不可替代化验：贵金属精炼计价、争议批次仲裁仍以火试金或 ICP-OES 实验室结果为准。

四、商业流程：从识别到对公结算

专业 B 端回收的标准流程通常为：

  1. 预约现场勘查 — 对方派员到货物现场目视分类。
  2. 分类装车 — 按金属种类分类装载，避免混料造成二次分拣成本。
  3. 磅秤过磅 — 三方磅或公磅出具地磅单。
  4. XRF 现场抽检 — 高价值批次（含铜、不锈钢、合金）扫描存档。
  5. 取样封存 — 争议批次双方留样，可选第三方化验仲裁。
  6. 价格锁定 — 按当日基础金属期货价 + 折算系数 + 加工费定价。
  7. 对公结算 — 出具增值税专用发票或回收凭证，对公转账。

五、采购方常见误区

误区 1：以颜色为唯一标准。氧化层会让紫铜变成"古铜色"，黄铜变成"灰绿色"——必须新切口或打磨后判断。

误区 2：用磁铁判定不锈钢就是 304。磁铁不吸只能排除铁基；201 不锈钢同样无磁，但镍含量低、抗腐蚀差，价格相差近 30%。

误区 3：XRF 读数 = 真实成分。表面镀层、氧化、油污都会影响读数，必须先做表面处理。

误区 4：轻信"通用价"。同样的"废铝"，光铝、6063 型材、铝屑、铝灰差价可超过一倍，按品类拆分定价才合理。

误区 5：不留样不留底。大批次、争议批次必须留样封存，避免后续无凭据扯皮。

结语

金属纯度识别是工业再生资源回收的"第一公里"，决定了从分拣、定价到对公结算全链条的合理性。对 B 端采购方而言，与其依赖单一鉴别手段，不如选择具备 外观经验 + XRF 现场扫描 + 第三方化验通道 三重能力的回收方，把识别风险前置到提货环节。循鑫已在京津冀工业园区落地标准化分拣作业流程，详见 服务流程 与 企业资质。
